[b]Edit events in the vanilla interface. Keep native XML.[/b]
Import Barotrauma event XML and edit Actions, branches and dialogue through a tree and property panel.

• Discover Actions and property hints from the current game; search in Chinese or English.
• Add, duplicate and move nodes, undo/redo, and batch-edit simple dialogue chains.
• Export new XML, copy an event or full file, and transfer to the vanilla node graph.

[b]Setup[/b]
Requires the [url=https://steamcommunity.com/sharedfiles/filedetails/?id=2559634234]LuaCs[/url] client runtime with C# mods enabled. At the main menu, press F3 and enter [b]baroeditor[/b], or use the vanilla event-editor entry. No server installation required.

0.1.1 preview. Complex Actions use generic attributes/XML; full graph round trips and complex event execution are not fully validated. Export creates a new file by default; source overwrite requires confirmation and backup.
