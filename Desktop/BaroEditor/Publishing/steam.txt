[b]不用开游戏，拖动画布编写《潜渊症》事件。[/b]
Windows 独立事件编辑器：66 个原版 Action、313 个属性，支持原生事件 XML 与扩展节点。

• 拖入动作、摆放节点、连接分支，搜索动作与属性。
• 剧本卡片、批量对话、比较条件、GoTo/Label 定位。
• 工程保存布局与悬空草稿；导入多语言词条，导出保留原标签。
• 导出新 XML 或复制内容；本地流程试播不执行游戏效果。

[b]English[/b]
[b]Build Barotrauma events on a draggable canvas—outside the game.[/b]
A standalone Windows editor for 66 native Actions and 313 properties, with native event XML and extension-node support.

• Drag Actions, arrange nodes, wire branches and search properties.
• Script cards, batch dialogue, comparison conditions and GoTo/Label navigation.
• Save layouts and floating drafts in projects; import localization while retaining original XML tags.
• Export new XML or copy content. Local walkthroughs never execute gameplay effects.

[b]Launch[/b]
After subscribing, open [b]steamapps/workshop/content/602960/3819572370/Standalone/BaroEditor.exe[/b]. Enabling the Workshop entry in game does not launch it.
Requires the [url=https://dotnet.microsoft.com/en-us/download/dotnet/10.0].NET 10 Windows Desktop Runtime x64[/url]; no LuaCs required. Keep the complete folder when downloading from GitHub.

0.2.2 preview. Floating drafts are saved in projects and enter event XML only after connection. Complex events still need in-game validation.
